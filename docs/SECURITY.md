# 安全默认约束

项目落地时按实际数据与部署方式补齐：

- 认证、授权与敏感数据处理要求。
- 密钥管理、环境变量及日志脱敏规则。
- 外部 API、Webhook 和文件上传的输入边界。
- 运行环境的文件、网络权限与恢复方式。

依赖、SBOM 与 provenance 见 `docs/SUPPLY_CHAIN_SECURITY.md`；漏洞反馈流程见根目录 `SECURITY.md`。

## Agent 执行

网页调研仅注册公开搜索与只读网页工具，不开放文件／命令。Tavily key仅在后端配置，不进入请求快照或工具输出；检索词会发送给搜索供应商，网页摘录会发送给模型供应商。抓取校验协议／端口、所有DNS结果和重定向，拒绝私网并固定已验证连接IP，HTTPS保留主机名证书验证；不使用环境代理，不执行网页脚本或绕过访问限制。预算、来源和恢复边界见[调研契约](design-docs/web-research-agent.md)。

OpenAI API key 只通过 `OPENAI_API_KEY` 环境变量或显式运行时配置注入，不写入源码、测试 fixture 或提交记录。请求会把当前上下文和工具定义发送到配置的 provider，接入真实环境前应确认数据处理、日志脱敏和网络出口策略。

- 沿用已配置的沙箱与授权边界，权限阻塞应记录并处理。
- Windows 原生执行方式见 `docs/WINDOWS.md`。
- 外部沙箱扩展是可选项，不随新项目默认分发；引入前必须确认官方来源、真实隔离范围、项目适配文档和权限边界。
- 引入外部沙箱前核验其真实隔离范围，不能仅凭提示词声称已有隔离就关闭现有保护。

本文件保持平台无关；具体沙箱路径、证书设置和审计操作由各平台指南维护。

## 即时协助与 HTML 预览

即时协助注册五种create工具，仅非空可信Skill目录时另注册get_skills；不装配检索、文件、命令、外部Skill脚本或开发助手权限。Skill不作为基本回答或产物的前提，当前产品白名单为空；通用可信加载保留，由显式目录白名单读取，正文／版本／SHA-256冻结在run输入，初始只披露元信息，按需加载正文。空目录合法且不暴露不可调用的空枚举工具；加载不授予额外权限。每run上下文、暂存产物与预算独立；SQLite为权威记录，不开启内核JSONL业务副本。

生成内容仍可能出错。HTML仅进入无同源权限的allow-scripts iframe，不进入宿主正文；不传凭据、不建立宿主工具桥接，CSP阻止外部子资源及连接。静态清理用于纵深防御，不是任意JavaScript证明。浏览器不可靠限制iframe自身脚本导航，且不提供CPU／内存配额，因此不能宣称严格网络或资源沙箱。当前仅预览模型生成的自包含教学动画，明确提示不输入敏感信息；详细限制见[即时协助契约](design-docs/instant-assistance.md)。

## 本地学习任务评测

评测仅对显式隔离的loopback后端发业务命令。默认每trial新建真实Uvicorn与空SQLite，拒绝作者默认库；health.storage_id与只读SQLite文件身份核对后才能写，文件身份改变即拒绝继续。指纹防误连，不替代认证、回滚检测或恶意宿主隔离。只停止自己持有的进程树，不按端口猜测杀服务。

schema-v3公开输入与私有学习者／参考／判据隔离；学生模型只见公开任务、学习者设定和真实对话，看不到正确答案或rubric。judge无工具，只有它得到私有标准；输出、来源与其中的指令均是不可信待判数据。即时协助仍无课程、无搜索、无文件／命令工具，可信Skill白名单为空；评测不授予新权限。

模型必须显式授权及指定角色模型，凭据不进入配置快照；带用户信息／查询／片段的provider URL拒绝，完整原始教学与评分材料只写忽略的data／允许的eval_result或仓库外。收费命令和模型请求先落盘in_flight，再仅发一次；业务HTTP和SDK客户端均禁重定向、自动重试。回执／响应未知不重发，失败不做JSON修复、模型fallback或模板补答。超时和本地进程结束不等于供应商停止计费。

完整证据、请求、原始模型响应、HTTP拒绝状态／正文与实际usage保留。输出usage超过请求限制时标记exceeded，停止当前执行中的后续评分／学生／批量控制请求，剩余项not_run保留在分母；未知usage不冒充零。上下文不足不截断教学内容；显式重评新增attempt，旧失败不覆盖，最新错误不能回退成旧通过。费用金额与远端取消状态无证据时为unknown，与已证实业务工程事实分开。

离线报告只读显式trial.json／batch.json，不连业务或模型、不执行模型HTML；输出只新建，全文转义、无远程脚本。不提供全局review/catalog扫描平台、旧schema兼容、ATIF或自动迁移。报告含用户材料与私有标准，不承诺从任意自然语言识别全部秘密，分享前须人工审查。`eval_result/2026-10-29/`为明确保护目录，禁止访问、扫描、迁移或改写；JSON、批量输入、报告、锁与后端路径在内容I/O前统一拒绝该目录，历史原始结果保留原字节。这是防误操作边界，不是对恶意并发宿主进程的操作系统沙箱。

作者控制通过不等于独立人工校准或人类对齐；模拟学生不证明真人收益。机制、命令和实际验收边界见[教学评测设计](design-docs/backend-evaluation-pipeline.md)及[使用说明](../evals/README.md)。

## 独立 V1 内核工具

工作区工具包必须由宿主显式装配，课程服务不注册它。文件工具拒绝工作区外路径／符号链接逃逸，覆盖与编辑要求已读摘要一致，写入采用原子替换；这些检查只防误操作，不是对恶意并发宿主进程的强隔离。旧 `read_file_tool` 保留兼容，不具有工作区约束。

写入与命令默认逐调用审批；缺审批通道、过期、拒绝与取消均不执行。审批不能从模型输出中获得，宿主必须展示具体调用并对审批 ID 决定。命令工具不是 OS 沙箱，获批后有宿主用户权限，cwd 不限制文件／网络访问；不要对不可信项目或输入自动批准。

进程 runner 使用环境白名单、已知凭据字面值脱敏、有界流式磁盘输出、超时及进程树清理。这不保证未知秘密或命令主动读取的本机文件被自动识别；审批与外部沙箱仍由宿主负责。

会话、显式记忆与完整输出可能包含个人信息或源码，调用者应放在私有目录并管理保留期限。默认验收仅写入忽略的 data，不能将原始会话、输出和密钥一起提交 Git。完整行为见[内核 V1](design-docs/agent-core-v1.md)。
