# 安全默认约束

项目落地时按实际数据与部署方式补齐：

- 认证、授权与敏感数据处理要求。
- 密钥管理、环境变量及日志脱敏规则。
- 外部 API、Webhook 和文件上传的输入边界。
- 运行环境的文件、网络权限与恢复方式。

依赖、SBOM 与 provenance 见 `docs/SUPPLY_CHAIN_SECURITY.md`；漏洞反馈流程见根目录 `SECURITY.md`。

## Agent 执行

OpenAI API key 只通过 `OPENAI_API_KEY` 环境变量或显式运行时配置注入，不写入源码、测试 fixture 或提交记录。请求会把当前上下文和工具定义发送到配置的 provider，接入真实环境前应确认数据处理、日志脱敏和网络出口策略。

- 沿用已配置的沙箱与授权边界，权限阻塞应记录并处理。
- Windows 原生执行方式见 `docs/WINDOWS.md`。
- 外部沙箱扩展是可选项，不随新项目默认分发；引入前必须确认官方来源、真实隔离范围、项目适配文档和权限边界。
- 引入外部沙箱前核验其真实隔离范围，不能仅凭提示词声称已有隔离就关闭现有保护。

本文件保持平台无关；具体沙箱路径、证书设置和审计操作由各平台指南维护。
