# 本地运行与可靠性底线

状态：2026-10-22 首个造课／课程库切片已完成真实模型、内置浏览器、取消晚到响应与冷重启恢复检查。产品以个人简历作品为目标，不建设企业级运维和安全平台。

## 必需行为

- 本地前后端可独立启动，真实命令与配置见 [README](../README.md)；拓扑见[架构](ARCHITECTURE.md)。
- health 区分本地存储可用、模型已配置和真实连通，配置存在不冒充调用成功。
- 模型等待期间 API 和课堂本地控制不被同步请求阻塞。
- 保存成功才显示成功；失败保留可重试状态，不吞错后跳转。
- 页面断线读快照，重启中断显式标记，不自动重复收费调用；已保存脚本和结果可以直接恢复。
- 本地模型调用默认并发 1，网络超时初值 120 秒可配置，校验修复最多一次；不无限重试，详见[模型工作流](design-docs/agent-workflows.md)。

## 最小观测与卫生

运行日志只需定位操作、run／course、阶段、耗时、错误及实际用量。数据库保留必要调用依据，控制台不打印密钥或整段个人内容。不引入指标集群、审计中心和分布式追踪。

默认回环监听、密钥留在后端本地配置、校验模型结构，不主动访问成果链接或执行代码。内容默认转义、不注入原始 HTML，Mermaid 严格模式，可点击链接限 http／https。这是展示内容的必要约束，不增加企业权限或安全平台范围。

## 验证与交付

验证见[真实验收](design-docs/real-validation.md)。Mock 路径已移除，不得作为验证方式或验收依据；缺少真实条件标记 blocked。CI 已接直接逻辑与实际本地服务，metadata 打包仍不等于产品发布，边界见 [CI/CD](CICD.md)。具体证据只在[首切片计划](exec-plans/completed/20261022-real-course-library.md)维护，不将局部通过扩写成 V01–V12 全部通过。
