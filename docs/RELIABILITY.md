## 课堂保存与恢复

- 课堂只接受完整schema_version=2；旧脚本返回script=null与format_error，保留版本、进度和run信息供显式操作。regenerate使用progress.version并保存旧原文，成功前不替换旧讲义；不补字段伪装兼容，不因打开页面付费生成。
- 进入、刷新和重连只读取讲义，不自动发起收费生成；prepare 和失败后的 retry 都由用户明确触发。课程、讲义及问答共用单 worker。
- 下一步先串行提交，再依据确认快照展示；断网或保存结果不明时暂停，保留同一命令 ID 和请求内容供显式重试，不积压未保存的展示步骤。
- 课堂快照顶层 version 覆盖问答／run 等全部课堂事实；progress.version 是位置与播放意图命令的乐观锁。回答完成可以只提升前者，不能靠进度版本合并完整快照。
- GET 原样返回权威 progress.play_intent，不在相同 version 下伪改数据。新建或恢复前端本地时钟始终暂停；网络恢复、轮询及字体／图形重排不会自动播放或推进。
- 提问先确认暂停，再保存当前 cursor、问题与回答 run；pending 期间禁止推进。回答持久化后保持可读，用户明确继续才恢复先前意图；重试问答以 interaction_id + run_id 区分此次确认。
- 查看位置与教学cursor分离，回看同时重建板书和文字；问题持久化anchor_step_id/anchor_object_id，只允许已确认前缀，不能引用未来对象。手动浏览停止相机跟随，可显式回到教学位置。课时手动完成要求已展示最终summary；提前退出不完成，理解检查反馈不判定掌握。完成事务写入activity_progress并提升课程版本，总览／列表／继续入口共用同一派生规则。
- v1 → v2 升级已有数据库前使用 SQLite backup 创建 `.v1-backup_*.bak` 一致备份，随后事务迁移四张新增表及回执字段；升级前仍须停止服务，不清空旧课程。这是既有v2课堂迁移；当前继续顺序迁移至v3，高于v3才拒绝降级打开。

## 练习／考核保存与恢复

- 题组prepare与失败retry必须明确触发，复用缓存及已保存run；GET、刷新、重连不生成题组、不建立attempt。练习只依据已有讲义，考核使用所属单元大纲与预算内已缓存讲义，不自动生成整单元。
- 单选／判断直接保存，多选先选择再确认。answer只保存判定与反馈，不推进；明确next才保存新cursor及question_started_at。用时为0–86,400,000整数毫秒，刷新不重置，超过24小时明确提示截断；不宣称可信考试计时。
- 最后答案仍为in_progress且无result，明确submit才同事务写入结果、活动完成及父课程版本；结果停留，回课程只导航。再练复用题组，历史URL固定attempt，不被后续尝试覆盖。课时已手动完成不重复增长；考核全错也可已提交，不表示通过／掌握，课时比例只算课时。
- 待确认命令保存原方法／路径／请求体／命令ID；释放前比较所有权，卸载页迟到请求不得删掉后继页面命令。慢GET可触发后续dirty读，但有有效结果就释放该批等待者，不等待全队列排空而卡住busy。
- v3升级前用SQLite backup保留旧v1／v2一致备份，原v2八表保留，新增quizzes／quiz_states／quiz_attempts。用户库无生成在途时冷重启十一表哈希一致、调用保持17，摄影两答案、cursor=2和题目起点不变；不是模型调用在途硬重启已验。
- 来源安全静态审查未确认问题，真实内容按React文本转义展示；不是全部危险输入均有浏览器覆盖。摄影光线题概念待纠正，见[教学内容债务](exec-plans/tech-debt-tracker.md)，不能把来源忠实或结构合法当成全部教学准确。

## 最小观测与卫生

运行日志只需定位操作、run／course、阶段、耗时、错误及实际用量。数据库保留必要调用依据，控制台不打印密钥或整段个人内容。不引入指标集群、审计中心和分布式追踪。

默认回环监听、密钥留在后端本地配置、校验模型结构，不主动访问成果链接或执行代码。普通内容由React转义；KaTeX保持trust=false、非法TeX报错、展开/尺寸限制，仅允许公式中的Unicode文本，不放宽HTML等其他严格规则。Mermaid严格模式、禁用HTML标签和配置指令；输出SVG再经DOMPurify及样式／引用白名单清洗，排除脚本、外部资源和危险链接，失败可重试渲染而非显示源码。原生diagram只渲染封闭节点/边类型。可点击外部链接限http／https。这是展示内容的必要约束，不增加企业权限或安全平台范围。

白板通过 FontFace 同时加载本地原始 Excalifont WOFF2 与小赖 Xiaolai TTF，使用 `Excalifont, Xiaolai, sans-serif` 字体栈，分别覆盖英文／数字／西文标点与中文／中文标点；任一加载失败均有明确提示且不算字体验收成功。Mermaid 等待两者就绪后测量，代码保持等宽，公式使用 KaTeX 专用字体，普通界面字体不变；图形重渲染不重置阅读时钟。
