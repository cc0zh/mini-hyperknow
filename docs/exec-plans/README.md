# Execution Plans

这个目录用于存放长期任务的执行计划，完整规则见 [`docs/PLANS_GUIDE.md`](../PLANS_GUIDE.md)。

- 进行中的计划放在 [`active/`](active/)
- 已完成的计划移到 [`completed/`](completed/)
- 新计划从 [`templates/execution-plan.md`](templates/execution-plan.md) 开始
- 暂时不做但需要持续跟踪的问题放到 [`tech-debt-tracker.md`](tech-debt-tracker.md)
- 移动计划后，更新仓库内所有指向旧路径的链接；不要保留指向 `active/` 的失效回链。
