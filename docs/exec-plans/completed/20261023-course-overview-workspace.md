# 课程总览学习工作台美化

## 目标、范围与风险

- 用户授权：一次完成课程总览美化，参考原站的课程侧栏与当前单元布局，保留米白、鼠尾草绿、淡紫配色。
- 验收：首屏呈现当前单元及真实状态；单元导航可分享、刷新和前后退恢复；课时学习／练习与考核入口可用；蓝图不伪装已生成；桌面、窄屏和键盘操作可用。
- 范围：总览布局、选中单元呈现、渐进披露、局部样式、真实已保存课程的浏览器检查及文档。不新增后端接口、模型调用、上传、项目提交或掌握度。
- 风险：布局改变不能改变课时完成／目录生成语义；局部样式避免污染课堂、造课页；既有用户文档修改保留。
- 设计基线：[学习体验](../../design-docs/learning-experience.md)、[蓝图工作流](../../design-docs/course-blueprint-workflow.md)。使用 ui-ux-pro-max；检索未提供适用的页面结构结论，本次以现有页面、真实状态和可访问性检查为依据，不持久化不相关推荐。
