## 决定与限制

- 页面只展示 Python 权威汇总，不在 JavaScript 重建判定或计算虚假总分。
- 原始报告摘要没有完整答卷，导出器显式打包 Case、冻结证据和必要过程信息；不导出模型凭据或完整评分请求副本。
- 首版以通用证据字段及可展开 JSON 支持不同业务，不执行教学动画或引入业务渲染依赖。
- 本任务不代表全业务真实模型验收或独立评分校准通过。
- 无实验定义的报告明确标为“所选结果”，不把已提供的部分结果冒充完整计划。完整实验报告保留 pending 与 invalid，并列出不匹配原因。
