# DeepTutor 产品内核调研

## 目标、范围与风险

- 目标：仔细核对 DeepTutor 中文文档与官方源码，以当前 mini-hyperknow 的产品边界、教学判断草案及同证据探针为对照，提出有实现证据、能被验证或否决的内核推进建议。
- 交付：筛选整理的研究报告、固定源码版本与关键调用路径、明确区分事实／推断／未验证的候选切片，不以功能清单代替产品判断。
- 包含：公开文档、官方源码静态阅读、当前项目直接相关代码与既有实验记录；必要的文档链接与骨架检查。
- 不包含：产品代码实施、付费模型调用、运行上游服务、上传／知识库等产品扩权、访问保护的旧评测目录、修改现有用户工作区改动。
- 风险：上游文档可能对应 dev 而非主分支；分别记录文档与源码版本，检查声明是否有真实调用链，不把论文结果等同开源实现或本项目收益。
- 授权：用户要求调研并获取灵感；不把研究建议当成产品实施授权。
