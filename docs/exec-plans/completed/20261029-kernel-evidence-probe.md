# 教学判断的同证据对照探针

## 目标、范围与风险

- 目标：检验同一模型看到相同原始学习证据时，结构化理解假设相较完整历史及普通摘要，是否改变下一步动作的针对性、不确定性处理和对错误笔记的纠正。
- 交付：一个独立、可复验的有限请求脚本，作者编写的固定场景，明确区分本地机制检查与真实模型证据的报告。不是另一套通用评测框架。
- 范围：仅实验脚本与文档，不接产品 SQLite、不改课程进度／计分／主流程，不访问保护的旧评测目录，不读取或改动其他项目的配置。保留当前全部已有工作区改动。
- 对照：三组都获得完全相同的原始学习记录与输出要求；分别不加笔记、加普通事实摘要、加结构化理解假设。加入证据不足、已经理解、旧假设被新证据反驳及错误假设等反例。笔记均标注为待核查材料，不是权威结论。
- 证明边界：固定证据快照不是动态学生，不把随后展示的固定材料冒充某个生成动作的干预结果；无自动教学总分，不把字段命中、动作变化或作者控制当教学效果。
- 预算与安全：每个矩阵最多18次真实调用，首轮每次输出上限768 token，第二轮统一1536 token；实际累计34次。SDK禁重试、拒绝重定向；请求先保存in_flight，未知请求不重发。完整请求／响应／实际usage写忽略的data，凭据不落盘。已取得沿用deepseek-flash的明确授权。
- 依据：[教学判断内核](../../design-docs/kernel-teaching-judgment.md)、[教学评测边界](../../design-docs/backend-evaluation-pipeline.md)、[安全约束](../../SECURITY.md)。原内核专题仍是草案，本实验不构成产品实施授权。

## 逐案例分析：不是教学评分

以下由同一助手检查自己编写的场景，未独立人工校准，不做统计显著性、学习收益或整体胜负判断；证据定位均为第二轮manifest的`case_id + arm + decision`。

| 场景 | 观察 | 可以／不可以解释为 |
| --- | --- | --- |
| fraction_single_error | 三组均保留一次错误的多种解释。假设组先要求学生口述原计算过程再用图检验；另两组更早引入通分和图示。 | 存在诊断动作顺序差异，但没有执行这些动作，不知道哪种产生更有效证据。 |
| fraction_procedure_only | 三组均区分算对与解释不足，均要求图示或理由表达。 | 不支持“只有结构化笔记才能发现会算不等于理解”。 |
| fraction_observed_understanding | 三组均承认已有计算／解释证据，但继续提出更复杂变式。原始历史组还错误声称两题分母均互质，而第二题分母4与6并非互质。 | 发现真实内容错误与可能的过度测验；不是结构合法就教学通过，也不能将一处错误归因为缺少笔记。 |
| units_error | 假设组先让学生独立把30厘米换成米，再重算；历史组直接给出“把2米改写成200厘米”，摘要组提示先用厘米表示。 | 假设组在本次输出中更直接地区分“不会换算”与“会换算但未应用”；只是一处机制信号，不是已证实的干预效果。 |
| fraction_stale_note | 三组均考虑后来的独立正确表现E2，不继续只据E1判定稳定误解。 | 原始历史已能触发重新判断；没有验证产品持久化的判断修订，更没有证明某个先前动作造成改善。 |
| units_false_note | 普通摘要组和假设组都明确拒绝与原始E1冲突的错误笔记；历史组也正确识别已观察能力。 | 模型在该反例中能核查笔记；这不是产品具有独立纠错机制的证据。 |

### 当前推进决定

- 不据此扩建能力图谱、学生画像、掌握度算法或课程重排，也不把草案直接接入业务。短历史、同原始证据、手写假设的本轮探针，没有建立结构化笔记的普遍额外价值。
- 后续候选研究对象收窄为“诊断动作的证据可区分性”：动作针对哪两个仍可能的解释，可能出现哪些可区分表现，以及该动作是否已把答案提示给学习者。不能只看是否引用假设ID或是否换了一道题。
- 这是实验方向而非新产品规则，不要求所有教学动作都做诊断，不承诺用确定性规则判断开放教学动作有效。若继续，应执行实际交互才能检查所获证据；当前不把固定快照冒充闭环。
- 停止本轮调用，不通过扩跑、挑成功案例或追加自动judge寻求更好看结论。当前交付是实验及其边界，不是“教学判断内核已实现”。
