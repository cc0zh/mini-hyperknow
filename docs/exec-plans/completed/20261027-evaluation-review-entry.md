# 统一本地评测报告入口

## 目标与范围

- 用户希望通过固定入口查看评测，而不是寻找每次实验目录中的HTML。
- 入口固定为忽略的data/evals/review/index.html，列出已导出的最新报告与历史快照；沿用现有详情页面，不重写判定或新建服务。
- schema-v2的execute／resume／regrade完成汇总后自动导出；report／compare也自动收录。review为无收费的入口重建／显式导入命令。
- 不扫描整个data目录，不移动或修改原始证据，不调用业务／模型，不把来源不明的开发预览自动加入真实结果。
- 保留已有工作区改动、旧CLI、未知费用及未校准标记；自动导出失败只告警，不改变已经取得的评测结论与退出码。

## 步骤与验收

- [x] 补充新入口、历史保留、静态安全、CLI及失败隔离的确定性回归。
- [x] 实现受写锁保护的目录索引、新文件快照及自动导出；JSON输出兼容。
- [x] 导入本次真实已有单轮结果，验证固定入口、链接与最新评分；完成相关测试及文档检查。

## 关键决定

- index.html只是可重建目录，不是证据或成绩来源。报告快照不可覆盖；只有带本功能标记的索引可以更新。
- 每一条报告绑定来源键；同一来源重新导出更新最新链接，旧快照保留。目录不重新聚合不同实验的通过率。
- 网页不执行模型HTML或加载外部资源；目录只使用转义后的文本与本目录生成的相对链接。
