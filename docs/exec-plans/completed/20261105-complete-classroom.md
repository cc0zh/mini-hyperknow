# 完整单课教学与白板主导课堂

## 目标、范围与风险

- 用户授权一次完成四阶段：参考课闭环、动态白板、插问与恢复、多类型课程验证。可重写相关代码，不发布、不清库、不改只读参考仓库。
- 当前优先级是完整授课体验：本课路线图 → 逐个要点讲解／图示／例子 → 理解检查 → 回扣总结；两路上下文装配与结算沿用已有基础，不另建新内核。
- 白板为桌面课堂视觉主体；点阵纸、黑色手写、紫色标题与浅黄重点；右侧互补讲解与提问次要。尊重 reduced-motion、键盘操作与安全渲染。
- 复用真实模型调用、SQLite、幂等和版本冲突处理。用户追加明确要求「不作兼容」：仅一套新课堂协议，旧格式明确拒绝，不自动转换、清空或收费重生成；共享调用方同步新契约或拆出职责明确的独立类型。
- 不做语音、移动端专项适配、任意模型 HTML 执行、自动认定掌握、发布或部署。
- 真实模型验收只用隔离数据目录；本轮实现授权包含必要的少量真实教学生成验收，凭据仅后端读取，不打印、不改写 `.env`。超时／失败原样记录，不用模板冒充。

## 协同契约

重建 BoardScript／BoardStep／BoardOperation 为单一新协议，不保留 v1 读取：

- script 含 `objectives: string[]`、`roadmap: {keypoint_id,source_keypoint_index,title,question}[]`；短标题通过0起来源索引逐项覆盖原大纲，避免长段原文挤满导航。v2要求开场、各要点 explain + example、至少一次 check 和末尾 summary。
- step 新增 `stage: opening|explain|example|check|summary`、`keypoint_id: string|null`、`focus_ids: string[]`、`check: {question,expected_answer}|null`；旧 title/narration/page/column/operations 保留。
- operation 含非空唯一 `object_id: string`、`target_ids: string[]`；新增 table（`columns: string[]`、`rows: string[][]`）和 diagram（`nodes: {id,label}[]`、`edges: {from_id,to_id,label}[]`）两种 kind；保留 content/items/language。已有 highlight/circle 通过 target_ids 引用已出现的对象／节点；所有对象和节点 ID 在课内唯一。
- 新增字段的具体默认值、v2 校验和返回类型由后端实施者与前端保持一致；使用前在沟通中确认任何变更。前端无需模型坐标，按稳定对象／关系自动布局。
- 插问继续沿用已确认前缀与显式继续；新增可选 `anchor_step_id`／`anchor_object_id` 定位回看位置，不能超出已确认前缀，保持教学 cursor 不回退。check 可通过真实课堂问答提交回答获得反馈，沿用持久化与插问恢复语义，不额外声称评分或掌握。
- 完成仅允许已展示最终总结；提前离开保留进度而不标记完成。练习提交完成的既有语义保留。旧脚本必须显式重新生成新协议，不能靠默认值伪装成新脚本。
