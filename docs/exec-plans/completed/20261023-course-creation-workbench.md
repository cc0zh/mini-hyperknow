# 造课工作台与轻量结构蓝图

## 目标、范围与风险

- 用户已批准讨论方案：将造课页从运行记录长页调整为紧凑任务工作台，左侧需求／阶段／资料，右侧课程结构，常驻主操作，点击节点查看详情。
- 验收：1440×900桌面首屏可见全部单元的紧凑总览与当前主操作；长目标、资料和节点说明不推走操作区；已提交偏好可查；节点浏览不发模型请求、不改变用户选择；确认一次与既有恢复语义不退化。
- 包含：造课专用布局、需求摘要、真实阶段与已保存数量、折叠调研／局限／技术详情、课程→单元→讲次／小节的轻量结构、节点详情、阶段化操作及可访问性。
- 不包含：首页／课堂／课程库重设计、自由拖拽或无限画布、修改生成流程、额外模型摘要、项目成果提交、思考题、多Agent、旧课兼容、部署或自动commit。
- 保留SQLite及现有API／useCommand／版本门禁。来源局限和阻塞错误不混淆；不伪造实时搜索动作、增长节点、预计剩余时间或百分比。
- 风险：操作区遮挡、过期蓝图被确认、阅读中自动抢焦点、CSS影响其他页面、长节点溢出。采用路由专用外壳、精确蓝图版本门禁、稳定选择、限定样式及真实浏览器检查。
- 原有项目暂缓相关工作区改动不覆盖、不混入；真实验收用独立验证数据，不操作用户课程库。若需新模型调用仅在明确的验收动作中产生，不为了前端展示重生成已有内容。
- 依据：[蓝图工作流](../../design-docs/course-blueprint-workflow.md)、[学习体验](../../design-docs/learning-experience.md)。
