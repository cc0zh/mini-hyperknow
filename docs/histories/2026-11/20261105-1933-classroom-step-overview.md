# 教师式讲解与单步白板总览

## 用户诉求

同步讲解应像老师实际授课而不是干巴巴的描述，并解释讲义是一口气生成还是逐步生成；白板仍是主体，每步内容缩小、集中并按清晰顺序在同屏展示。

## 结果

保留整课一次生成、播放逐步揭示。增强教师式短段提示，单步纸面按编号紧凑排布并默认完整入镜，提供点选放大和本步全览；修复真实内容的换行/表格/公式溢出、回看段首及未备课空引用。旧缓存不自动改写，新增显式二次收费确认入口。真实新讲义、旧三类讲义、两桌面视口与工程门禁分层通过，教学措辞及未覆盖边界保留。无清库、提交或部署，验收服务已停。
