# 产物意图误判修复与移除预判

当前状态：下方第一阶段的词法修复已被用户确认的后续移除方案取代；现行契约以“后续决定”及即时协助设计为准，原阶段测试结果保留为历史事实。

## 用户诉求

修复“看不懂白板／不理解动画”被误判为禁止产物的问题，不回退独立即时协助、课程删除与运行恢复，也不重新引入强制Skill、强制澄清或文案猜续讲动作。用户确认本地实施，不包含收费调用、提交或发布。

## 改动与原因

- [意图解析](../../../src/hyperknow/assistance_domain.py)不再以裸“不”字认定拒绝，改为匹配明确拒绝与生成／使用动作；保留闭合列表否定和分句作用域。
- 紧邻产物词的理解困难陈述本身也不作为强制创建请求；后续明确创建或拒绝分别生效。不通过删除禁止项消解真正矛盾的指令。
- [领域回归](../../../tests/test_assistance_domain.py)覆盖原始误判、理解困难、明确拒绝、动作与题型别名及矛盾指令；[临时SQLite回归](../../../tests/test_assistance_storage.py)验证新请求可完整保存、缺失指定产物仍拒绝、明确禁止仍拦截。
- 同步[即时协助契约](../../design-docs/instant-assistance.md)。仅修改词法意图派生，不改Prompt、Skill、API、课程状态、worker或工具／提交权限，不改写历史run冻结输入。

- `npm.cmd --prefix web test`：97项通过，包含当前运行归属、恢复命令、显式建议动作及零澄清；`npm.cmd --prefix web run typecheck`通过。

- 未运行完整CI、真实模型／搜索或浏览器验收，不宣称教学质量改善；没有读写作者默认数据库、覆盖旧失败、提交或发布。

## 保留边界

仍是有界关键词启发式，不是任意中文语义分类器，不覆盖全部长距离否定或复杂指代。真正同时要求与禁止同类产物时仍保留禁止，不静默放宽安全／保存门禁。本次沿用既有解析和事务机制，未新增架构概念，学习要点随本记录保留。

## 后续决定：移除自然语言预判

用户认为关键词预判收益过低，确认将意图理解交给教学模型；另明确选择即时协助统一不传供应商输出Token上限，接受普通回复输出成本可能增加。不是继续扩充词表，也不新增分类模型、强制Skill、澄清或产物选择器。

### 最终改动

- 删除产物意图词表／解析函数，新run仅冻结原始文本和既有业务上下文，不派生requested_artifacts／forbidden_artifacts。
- 移除工具层的类型／拒绝猜测门禁、生成层必产出检查及提交层对应分支。保留工具白名单、Schema、每轮至多一个产物、续讲状态、版本／幂等、取消屏障和原子保存。用户产物要求改为模型遵从目标，不再提供由关键词派生的确定性承诺。
- 模型可见输入排除历史派生字段，旧run输入和审计原文不改写；可信Skill快照仍只经加载工具披露。实际教学提示标记为assistance-v3，回复Schema版本仍为2。
- 所有即时协助请求及格式修复均使用max_output_tokens=None；8192仍只是默认上下文预留，64000上下文预算、调用次数、时限、HTML大小及动画成功暂存后的投影不变。课程、调研和Grader策略不改。
- 同步即时协助契约、架构和技术债；保留历史验收文件。职责边界的可迁移思路见[学习记录](../../learnings/2026-10/20261027-intent-is-not-permission.md)。
