## 阅读路线

**如果困惑的是「产品内核到底是什么」**，只读[产品内核](product-kernel.md)。该长期定义保留，但不是当前课堂交付的前置重构；当前教学结构与交互见[完整白板课堂](learning-experience.md#4-白板课堂)。旧内核稿[教学判断内核](kernel-teaching-judgment.md)已归档，其中的四层假说、掌握度与门槛讨论属复议材料，不进入实施基线。

不知道某项业务主要改哪里、依赖什么或影响谁时，先读[现行业务与改动影响入口](../ARCHITECTURE.md#10-现行业务与改动影响入口)。它是当前业务关系与验证定位的统一入口；下列专题承载详细契约，计划承载实际验收，不能用历史审计替代。

1. [产品内核](product-kernel.md)：产品自己持有并负责什么——两路上下文、学习者状态三路、待答事项、装配与结算，以及区分机制与提示词的硬测试。
2. [产品设计](product-design.md)：首版范围 R01–R11、排除项与完成定义。
3. [页面与学习体验](learning-experience.md)：导航、生成／播放状态、活动和恢复语义。
4. [架构总览](../ARCHITECTURE.md)：当前事实、业务全路径与改动影响、共享/独立边界、验证入口，以及技术栈、目录和运行拓扑。
5. [模型工作流与上下文](agent-workflows.md)：场景输入输出、真实调用、内容校验和有限修复。
6. [领域对象与持久化](data-model.md)：SQLite 权威数据、状态、计分、事务及恢复。
7. [API 与事件](api-and-events.md)：REST 命令／查询、WS 通知与客户端同步。
8. [真实验证](real-validation.md)：拒绝 Mock、当前测试债、V01–V12 及证据要求。
9. [参考证据与缺口](reference-and-gaps.md)：用户确认、原站局部证据、Clone 事实和必要补齐。
10. [网页调研 Agent](web-research-agent.md)：独立调研、真实搜索／阅读、来源与预算；新造课接入及验收由蓝图工作流承接。
11. [蓝图确认与单元展开](course-blueprint-workflow.md)：调研接入造课、一次全局确认和逐单元局部保存；实施与验收状态见其计划。
12. [Agent 运行时 V1](agent-core-v1.md)：模型调用、工具、权限、会话、记忆、预算压缩和模型分层。**这是运行基础设施，不是教学策略**；与课程显式业务工作流隔离，不代表产品已接入文件或命令工具。
13. [即时协助与可选 Skill](instant-assistance.md)：独立教学会话；可信按需Skill、显式建议动作和反馈刷新恢复；四类轻量产物，不做资料、检索或课程关联。
14. [面向学习任务的教学评测](backend-evaluation-pipeline.md)：固定任务、真实隔离场景、冻结证据、无答案学生模拟、分维判据与矩阵比较。是检验工具，不产生产品机制；真实覆盖与预算边界见验收计划。

教学职责重构：提示位置、零澄清和可选Skill的当前实施及验证见[执行计划](../exec-plans/completed/20261026-teaching-boundaries-refactor.md)。不兼容旧格式，不扩展产品范围，不以本地检查替代真实模型验收。

## 状态与维护边界

- 2026-10-27用户明确项目仅适配与验收桌面浏览器，不再维护移动端；已有响应式降级及历史验收事实不删除。范围以[产品设计](product-design.md#4-明确不做)为准。
- 2026-10-29用户取消“掌握度算法、自适应重排整门课程、及格门槛”三项限制，强制解锁与AI项目自动评审仍排除在外。2026-10-30内核定义收口为[产品内核](product-kernel.md)：取消限制只说明「允许做」，不构成内核要求，也不允许无证据认定掌握或通过。
- 术语只保留一个「内核」：产品内核指产品持有并负责的上下文装配与结算；`agent-core-v1` 是 Agent 运行时；`backend-evaluation-pipeline` 是教学评测工具。三者不得混称。
- 产品专题为首版实施基线；产品裁剪来自用户确认，工程决定由本项目采用，不冒充原站技术方案。新增讨论草案以自身状态为准，不构成实施授权。
- 实现状态在架构“当前事实”和[质量状态](../QUALITY_SCORE.md)说明，验收证据留计划／执行记录，各专题不得把目标写成已实现。
- 一主题一文档；当前数量较少采用平铺，不复制 ActSpace 全部专题及复杂度。
- 产品原则见[PRODUCT_SENSE](../PRODUCT_SENSE.md)，协作原则见[core-beliefs](core-beliefs.md)。
- 外部阅读入口见[参考资料](../references/design-document-references.md)，本轮记录见[history](../histories/2026-10/20261022-1456-product-architecture-baseline.md)。
