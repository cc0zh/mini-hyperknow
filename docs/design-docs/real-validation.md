# 真实验证与交付验收

状态：2026-10-22 造课／课程库、真实白板课堂及练习／考核均已完成各自切片范围的模型及内置浏览器验收。V01–V12 未整体通过，切片验收不能代替完整学习链路。
关联：[产品范围](product-design.md)、[体验](learning-experience.md)、[质量状态](../QUALITY_SCORE.md)。

## 1. 不使用 Mock

用户明确拒绝 Mock 测试。本项目不新增或运行 Mock 模型队列、Fake SDK、HTTP／WS 桩、前端接口拦截、录制响应回放、内存仓储替身来替代真实依赖或证明业务完成。

允许：直接测试真实计分、状态、schema、上下文选择函数；在独立临时目录运行真实 SQLite；启动真实前后端，接真实模型和本地数据库；浏览器手工或自动化实际操作。确定性函数直接输入具体值不属于依赖替身。

校验失败可直接向真实校验函数输入无效内容，不用假模型“返回”它。网络失败可通过停止实际进程或禁用验收进程的真实网络来验证，明确覆盖边界，不伪造响应。测试不得触碰作者既有数据。

## 2. 当前无 Mock 检查入口

历史 MockLLMService、Fake SDK、SDK 客户端注入及 Mock／patch 测试已经移除。`tests/test_agent_core.py` 只检查真实函数和文件工具，`tests/test_course.py` 直接检查 schema、状态、取消调用门禁及临时磁盘 SQLite，`tests/test_http.py` 启动实际 Uvicorn 和真实 HTTP／WebSocket 连接，刻意验证缺配置而非伪造模型成功。

课堂新增 `tests/test_lesson.py` 与 `test_lesson_http.py`，使用真实磁盘数据库、v1备份／迁移、事务失败回滚、并发命令、上下文前缀与实际HTTP／WS；前端直接检查单时钟、暂停／继续意图、快照版本、命令恢复及真实KaTeX渲染，不注入服务响应。

练习／考核新增 `tests/test_quiz.py`（28项规则／临时真实SQLite）及 `test_quiz_http.py`（6项实际HTTP／WS），覆盖结构／来源预算、v2备份迁移、计分边界、反馈／next／submit事务、并发／幂等、历史尝试及恢复。实际HTTP测试的确定性题组输入只证明规则与存储协议，不冒充模型生成；真实三次出题另留证据。前端直接检查命令所有权，真实浏览器另验6秒网络延迟下反馈与pending释放。

统一执行 `uv sync --frozen` 后，`npm.cmd run ci` 或 `npm.cmd run test:python` 走上述检查；前端 `npm.cmd --prefix web test` 直接验证状态合并、选项和命令规则，不拦截接口。浏览器检查必须连接实际后端，不注入课程或回放响应。

无凭据的公共 CI 可运行文档、编译、类型、直接逻辑与真实 SQLite 检查，但只能标记静态／本地检查通过，真实模型及浏览器验收待执行，不把 skip 写成通过。

通用内核 V1 新增真实磁盘 JSONL／显式记忆、工具审批线程、rg、Windows 子进程与直接预算／消息协议检查，不使用 provider 替身。独立 `scripts/verify_agent_v1.py` 接真实配置验证只读工具循环、真实摘要及会话重开，会收费且不触碰课程数据库；实际调用／usage与未覆盖边界见[内核升级验收](../exec-plans/completed/20261022-agent-core-v1.md)，不替代下述产品场景。

## 3. 真实验证前提

- 启动本次实现版本的前后端，使用独立可保留的验收数据目录。
- 从本地配置取得真实 endpoint、模型和凭据，不在聊天、日志或截图里暴露密钥。
- 记录代码版本、时间、实际模型、浏览器和数据目录的脱敏标识。
- health 的“已配置”不足以证明连通，至少一次真实生成成功才算模型可用。
- 缺凭据、限额、网络或模型能力时标记 blocked，说明条件；不降级、不伪通过。

## 5. 演示输入与内容核查

建议主线：我会 Python 基础，想用两周理解 asyncio，并完成一个并发请求小工具。适合核查代码、机制图、题目和项目，但不是限定学科或写死样本。

另用不同学科或基础／时间要求的真实输入检查是否只是通用模板换标题。人工核查：

1. 目录有相关概念和合理顺序，能解释需求对范围的影响。
2. 讲义至少有具体机制、例子或推导，不仅重复泛泛目标。
3. 插话利用当前内容，答案具体，不混淆其他课时。
4. 题干、选项、答案、解释一致且对应课程。
5. 项目适合主题，完成仅表示成果保存。

不以“黄金回答”全文一致检验非确定性模型。格式断言、人工知识核查与行为检查分别记录，不互相替代。
