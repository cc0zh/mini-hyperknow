常驻导航只保留首页、我的课程及当前课程的必要入口。问答历史在课堂内，活动结果在所属活动内；不额外建设独立聊天历史中心。

沿用 Clone 所反映的页面分工、票券／卡片视觉和白板布局，不引入新品牌视觉系统。样式及局部展示组件可以参考或选择性复用，业务状态不整包照搬。桌面优先，至少保证当前板书可读，不把手机适配作为首版门槛。

## 2. 课程创建

| 状态 | 含义与允许操作 |
| --- | --- |
| `queued` | 已保存学习需求，等待本地模型执行槽；可取消 |
| `clarifying` | 正在生成澄清问题；可取消 |
| `awaiting_answers` | 等待用户明确提交或跳过；不占模型槽，不以静默超时跳过 |
| `awaiting_blueprint` | 全局单元骨架已保存，等待一次确认或调整意见；不自动展开、不占模型槽 |
| `generating` | 根据需求与答案生成课程结构；显示实际阶段，可取消 |
| `ready` | 校验并保存的课程已可进入；不等于全部讲义和题目均已生成 |
| `failed` | 请求或内容校验失败，显示原因；可手动重试 |
| `cancelled` | 用户取消；晚到的模型响应不创建课程 |
| `interrupted` | 进程中断了在途运行；可手动重试，不假装仍在后台生成 |

澄清题由真实模型生成，不强制所有主题采用固定四题；题目类型和允许自定义须反映在界面。用户提交后保存问题、选项文字和答案文字，不只传无法解释的选项 ID。

阶段展示来自实际工作开始／完成。没有可计算的分母就展示阶段而非百分比；模型没有返回usage就不显示Token数。当前[蓝图工作流](course-blueprint-workflow.md)将生成分成research／blueprint／units，蓝图确认一次后逐单元提交并实时呈现，不以预设定时器伪装节点增长。部分目录显示“目录完善中”，不宣称整门课进度100%；完整目录后才计算课时比例。

重试建立新的 run，保留失败／取消记录并复用已经确认的需求及答案；不覆盖原 run 身份。等待答案的 run 刷新后仍能恢复；已完成 run 重新打开指向同一课程。

造课页先展示全部单元的顺序、目标与实际状态，再按需查看讲次、小节、项目和考核详情，不让长简介或调研日志挤走确认操作。需求／资料与课程结构分别滚动，当前主操作常驻底部。已保存偏好可查，资料失败和局限有独立提示；浏览节点只读、不触发模型，后台展开不自动切换用户正在查看的单元。结构图不提供自由编辑／拖拽，详细交互约束见[蓝图工作台](course-blueprint-workflow.md#造课工作台)。

## 3. 课程路径与完成语义

- 保留 `Course → Unit → Lecture → Session`；Exam 及 ProjectStage 属于单元，项目目标属于课程。
- 默认展开首单元，其他单元可折叠；不新增前置解锁校验，用户可直接选择活动。
- 采用参考实现已存在的课时完成比例：已完成课时数／总课时数，展示为“课时进度”。考核、项目单独显示状态，不把该比例称作掌握度或全部活动完成率。
- 采用参考实现的下一项顺序：依单元查找未完成课时，其次项目阶段，再考核。总览和侧边继续入口使用同一个结果；若原站进一步证据存在冲突，先登记差异再改规则。
- 当前课时有讲义后可手动标记完成，不要求必须播到最后，也不把播完自动当作完成／掌握。提交一次练习也完成课时，不要求全部答对；进入练习本身不完成课时。
- 考核是“已提交／已完成”，不是“已通过”；项目是“成果已保存／阶段已完成”，不是“评审通过”。
- 全部课时完成后允许课时进度为 100%，仍清楚展示未完成考核／项目；只有所有活动均无下一项时隐藏继续按钮。

上述比例与顺序来源于 Clone 源码，本项目明确采用，不能写成已独立核实的原站完整规则。

当前 derive_course 统一为列表、总览与继续入口派生课时比例、completed 及 next_item；手动完成提交后提升课程版本。练习／考核已保存真实作答与结果，项目仍无提交页，界面明确标为未开放；课时比例不能掩盖其他活动状态。

## 4. 白板课堂

进入、刷新和重连只读取已保存快照。无讲义时展示“准备本课讲义”，用户明确点击后才启动真实模型；已有生成记录展示实际 queued／generating／失败等状态，失败／取消／中断由用户明确重试。已有脚本直接复用，不因刷新收费再生成，不能出现空白画布却宣告就绪。

每个 `BoardStep` 绑定 title、narration、稳定 step_id、page／column 与 operations。当前八种 operation 为 text、list、code、formula、box、arrow、highlight、mermaid；页／栏是步骤位置，不是额外 operation。page 从 1 起，column 为 1 或 2，顺序只能非递减。不支持的操作在校验时暴露，前端也显式报错，不静默丢弃。

Board 只呈现确认 cursor 之前的步骤前缀，按页栏重建，不用累加 DOM 模拟进度。页栏历史可导航，review 选择与播放器确认 cursor 分离；回看不改变新板书写入位置，也不改变问题锚点。框与箭头当前是有内容的基础展示，不是自由绘图编辑器。

### 白板手写体

白板普通文字按 **Excalifont + 小赖 Xiaolai** 分工：英文、数字与西文标点使用 Excalifont，中文与中文标点使用 Xiaolai。通过 FontFace 同时加载两款本地字体，字体栈为 `Excalifont, Xiaolai, sans-serif`，仅用于普通板书与图形标签。资源接入不等于浏览器验收完成；当前资源与验收见[字体参考](../references/whiteboard-font.md)，版权与完整许可见[字体 NOTICE](../../web/public/fonts/NOTICE.md)。

- 白板标题、正文、列表和框图中的普通文字使用上述字体栈，分别覆盖拉丁与中文字形；不以仅对拉丁字母生效的通用 cursive 声称满足中文手写要求。
- 代码保留等宽字体和原缩进；公式由 KaTeX 使用专用数学字体。Mermaid 普通标签使用上述手写字体栈，两款 FontFace 均加载完成后才测量排版，仍须核查节点尺寸与连接线，不破坏图形可读性。
- 导航、按钮、课堂旁白与问答面板沿用界面字体，不把全站改成手写风。字体不改变文本内容、步骤 ID 或播放状态，也不要求笔画动画、自由涂鸦或手写输入。
- 使用未修改的官方资源：`/fonts/Excalifont-Regular.woff2`（官方 Latin 子集，24,956 bytes）与 `/fonts/Xiaolai-Regular.ttf`（v3.126，22,220,806 bytes），不依赖用户安装字体或运行时第三方字体 CDN。两者均采用 OFL 1.1，随资源保留各自版权与完整许可证。
- 两款字体均就绪后再确定依赖字形的板书布局，避免刷新后字宽变化导致重叠或截断；字形缺失或任一字体加载失败时保持文字可读，但不能把回退字体当作指定字体验收通过。
- 真实浏览器分别核查两款字体实际加载与字形使用，检查英文、数字、西文标点、中文、中文标点、中英混排、长文本、公式／代码隔离、框图标签和刷新后的排版；不只检查 CSS 中存在 font-family 声明。

### 内容渲染边界

普通板书、旁白和问答由 React 转义，仅显式 http／https 文字转换为外链，附带 noopener／noreferrer；代码不执行。KaTeX 使用 trust=false、严格模式与展开／尺寸上限。Mermaid 使用 strict、禁用 HTML 标签，拒绝配置指令／frontmatter，生成 SVG 后再用 DOMPurify 和样式／引用白名单清洗，禁止危险元素、事件和外部资源，保留安全绘图样式。

公式或图形不可解析时显示“板书渲染失败”并允许重试渲染，不默默显示源码，不自动再请求收费模型。字体／图形重排不推进步骤或重置阅读时钟；当前并不支持任意 HTML 教学组件。

### 播放与插话

| 播放状态 | 主要行为 |
| --- | --- |
| `loading` | 载入或生成讲义，不允许推进 |
| `paused` | 初始／恢复或暂停进入；下一步只推进一项，显式开始播放后才启用自动阅读节奏 |
| `playing` | 按本地阅读节奏逐步推进；不是语音时长，也不伪称实际授课分钟数 |
| `answering` | 已保存提问并请求回答；主讲解停止，不接受重复问题请求 |
| `answer_ready` | 回答已保存并完整可读；保持原板书位置，提供“继续课堂” |
| `finished` | 所有教学步骤展示完成；用户仍需明确手动完成或进入练习后显式提交，播完不自动完成 |
| `error` | 当前操作失败，保留已保存位置和历史，允许重试 |

上表是体验状态说明，不是一套独立持久化枚举；当前由脚本／run、单一 PlaybackClock、busy／pending、hold 及错误状态派生。阅读间隔根据已确认旁白字符数估算并约束在 4–30 秒，不是语音或实测授课时长。

只有一套播放器控制推进。点击下一步取消旧计时并申请写入互斥；下一步先经后端确认，再更新板书／旁白，不能先展示后补保存。忙碌、结果不明、问答 hold 或离线时不推进；暂停取消自动计时，没有逐字动画位置需要恢复。同一步不重复追加视觉元素。

提问先本地停止并提交暂停，确认后以新的 progress.version 保存问题、原 cursor／step_id、was_playing 与 question run，期间不能推进或重复提问。回答持久化后完整保留，不按固定 600ms 覆盖；用户点击“继续课堂”才返回：原来播放则继续，原来暂停则保持暂停。问答始终可回看；失败／取消／中断可明确重试，不跳步。继续确认以 interaction_id + run_id 为身份，重试后的新回答仍需确认。此恢复语义不冒称原站细节。

首次进入从准备态开始；已有脚本时以 cursor=-1 或最近保存位置恢复，前端本地 playing 初始化 false。GET 返回 SQLite 权威 play_intent，不为了暂停 UI 在相同 version 下篡改为 paused；即使已保存 playing，快照、轮询和重新联网也不会自动调用 play，用户需明确继续。

完整课堂快照按顶层 version（session 资源版本）合并；进度命令用 progress.version 乐观锁，二者不能混用，问答 ready 可以只改变顶层版本。写入结果不明时保留 sessionStorage 中原请求与命令身份，重试同一命令；确认冲突后读取权威快照再重新操作。

当前脚本没有思考题字段，课堂也没有 thought-answers 或假选项入口。长期目标仍保留：要点只表示讲到，不表示掌握；思考题须实际保存答案并提供反馈，选择型用经校验的标准答案，开放型明确标注模型反馈，不生成掌握分。不能保留“点击任意选项只关卡片”的假交互。

## 5. 作答、结果与项目

练习／考核已有实际页面、端点与记录，本阶段范围的真实验收见[完成计划](../exec-plans/completed/20261022-real-practice-exams.md)；项目成果提交仍为未来目标，不以占位交互冒充完成。

- 练习与考核支持单选、多选、判断，沿用参考的单选即时判定、多选提交判定、答案解释及跳过行为；不新增主观卷自动评阅。
- 每题保存确认后停留反馈，明确下一题才持久化新位置和计时起点。末题作答不自动提交，点击“看结果”才汇总并写完成事实；提交后停留结果页，“回到课程”只导航、不二次提交。
- 显示正确数、得分、星级、连击等个人结果，不显示伪用户排行榜。具体计分见[数据模型](data-model.md)。
- 重新打开优先读取最近尝试，URL固定所选attempt，历史结果不被其他标签的新尝试覆盖。“开始／再练一次”是明确写命令；已有未提交尝试复用，已提交后才新建。读取／刷新不创建尝试、不重置计时、不出题；再练复用原题组。
- 作答用时根据已保存question_started_at计算并沿用原命令，服务端只收0–86,400,000的整数毫秒；超过24小时明确提示截断到24小时，不把刷新当新起点，也不宣称可信考试计时。
- 项目尚未实现；长期目标至少需要非空文字或链接；只校验存在性，不访问用户链接或执行提交代码。保存成功才能显示完成，失败保留编辑内容并允许重试。

## 6. 跨页恢复与异常

网络断开不等于取消模型运行，但本地课堂暂停推进。重新连接后先确认资源订阅生效，再读取已保存快照；通知不可用时明确显示 HTTP 同步并轮询，不伪装已连接。读取期间的更新触发再读，旧快照不得覆盖更新版本或已确认命令。不能仅凭本地计时器显示后台进度。进程重启将未终结 run 标为 interrupted，不自动重新发起收费调用，已有讲义直接读取。

没有课程、尚未准备讲义、生成失败与数据缺失分别有明确状态；题组同样如此，不全部渲染成正常空列表，不吞错后直接跳转。当前分阶段验收与未覆盖时序见[可靠性状态](../RELIABILITY.md#验证与交付)，不替代思考题／项目或完整V01–V12验收。恢复验收边界见[真实验收](real-validation.md)，原首切片证据保持原样。
