# 把评分器也当成待测系统

自动评测里，“回答经过评分”与“评分值得相信”是两件事。评分器可以稳定输出合法JSON，却反复漏掉真实错误。

## 为什么全绿仍可能不能合并

假设回答的主公式正确，但附带解释把“两个导数相乘”说成“乘积函数的求导”。评分器若只核对主公式，就会给整项数学检查pass。此时增加同类题目可能只让错误更有规模，而不会让尺子更准。

因此要分开保存三层结论：业务是否执行并落盘、原评分器判了什么、复核者是否接受这个候选。第三层不能偷偷改写第二层。

## 怎样用反例检查尺子

1. 从真实答卷摘取可定位的错误片段，保留原文、原评分和原始证据。
2. 给出最小反例或正确关系，而不是只说“感觉太长／不够严谨”。例如选一个数值点，即可检验导数乘积是否真的等于乘积函数的导数。
3. 把正确、明显错误及边界样本一起复核。只挑原本通过的例子，无法估计错误接受风险。
4. 改评分口径时产生新版本；改完后回看未用于调节的样本，不能覆盖旧实验或把助手判断冒充独立真人校准。

## 容易混淆的另一件事

评分材料超过预留预算，是测量未完成，不等于教学内容不合格。显式扩大预算后可以只评原答卷，但那是新评分配置；原异常要留下，也不能把它拼成原配置整体通过。

先判断“尺子没量完”还是“尺子量错了”，再决定补充评分、修评分器或改教学。不要一遇到红灯就修改回答，也不要一见绿灯就自动合并。

## 一次不该采纳的局部改善

在后续固定五份材料的对照中，要求“检查所有相关解释和卡片、不要只看主公式”的提醒，确实抓住了一处求导类比错误；但真实卡片仍把任意步长当作局部小量，评分器照样判pass。数学反例能证明卡片错，却不能保证评分器会读出这个错误。

同一对照也保留数学正确卷、已定义中间变量和合理近似：否则“一律更严”可能只是把误接受换成误拒绝。实验前规定两类真实错误都必须抓住；只抓住一类就撤回，而不是事后把门槛改为“有一点改善即可”。本次没有重新生成教学回答，更没有测量学习者表现。
